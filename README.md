# 🐍 Python Task Manager (CLI)

Ek simple aur efficient Command Line Task Management Tool jo Python aur JSON File Handling ka istemal karta hai.

## ✨ Features
- ➕ Naye Tasks Add Karein
- 📋 Pending aur Completed Tasks Dekhein
- ✔️ Tasks ko Completed Mark Karein
- 🗑️ Tasks Delete Karein
- 💾 Automatic JSON Data Persistence (Data Save Rehta Hai)
